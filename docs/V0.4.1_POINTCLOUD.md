# v0.4.1 — Direct Point-Cloud Monitoring

## Height estimator
`h_Dx` = P95 of normalized point-cloud Z values >= `min_veg_h_m` inside the fixed tree buffer.

Additional metrics: `p99_Dx`, `t10_Dx`, `t20_Dx`, `t30_Dx`, `np_Dx`, `qc_Dx`.

## Monitoring
For D2+:
`dh_D2 = h_D2 - h_D1`

No fixed agronomic growth threshold is applied. Residuals are re-check flags based on technical QC and Tukey outlier fences.

## Residual outputs
- `residual_point_Dx.shp`
- `residual_zone_Dx.shp`
- `residual_zone_Dx.csv`

Residual polygons retain TREE_ID and reason; they are not dissolved.
