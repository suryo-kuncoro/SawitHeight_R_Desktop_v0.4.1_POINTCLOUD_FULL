Wajar berkisar 10–25% tergantung lebar gawangan terbuka. Jika < 5%, referensi ground dari dense cloud sangat terbatas — pertimbangkan DTM independen atau GCP sebagai referensi tanah (Step 03B).

03B

Konsistensi Terrain & Posisi Antarperiode

PPK menjaga georeferensi; QC terrain tetap wajib karena delta tinggi dihitung dari tinggi relatif terhadap tanah.

✓Kondisi proyek
Akuisisi menggunakan PPK, sehingga konsistensi posisi horizontal/vertikal antarflight lebih terkontrol. Namun PPK tidak menggantikan kebutuhan model terrain: tinggi tanaman tetap harus dinormalisasi terhadap permukaan tanah yang valid.

Untuk setiap semester, gunakan prosedur klasifikasi ground dan normalisasi yang sama. Jangan membandingkan nilai Z absolut dense cloud antarperiode. Yang dibandingkan adalah tinggi relatif setelah normalisasi.

Pilihan referensi terrain

Fallback proyek — CSF → TIN

▲Quality gate
Jika ground point sangat sedikit, terdapat gap terrain, atau normalisasi menghasilkan pola negatif/positif sistematis, jangan lanjut menghitung delta. Perbaiki terrain terlebih dahulu atau gunakan DTM independen yang tervalidasi.

Ekstraksi Tinggi Langsung dari Point Cloud — Buffer 2 m

P95 sebagai estimator utama sementara; P99 dan mean top 10/20/30% disimpan untuk evaluasi.

Untuk TBM pada proyek ini, tajuk antar-pokok belum saling bersentuhan. Karena itu buffer tetap radius 2 m dipertahankan. Risiko point cloud tajuk tetangga masuk ke buffer relatif rendah, sementara prosedur menjadi sederhana dan konsisten antarsemester.

✓Estimator utama v0.4.0
P95 digunakan sebagai h_main sementara karena belum tersedia tinggi lapangan untuk kalibrasi. Jangan menganggap P95 sebagai standar biologis final; P99, Top10, Top20, dan Top30 tetap disimpan agar dapat dievaluasi ketika data referensi tersedia.

6.3 — Hitung P95, P99, Mean Top 10/20/30%

Titik sangat rendah dibuang dari estimator tajuk. Threshold di bawah ini hanya filter teknis vegetasi/ground residual dan harus tetap lebih rendah dari tinggi sawit termuda.

R CONSOLE
min_veg_h <- 0.30  # meter; filter teknis, bukan threshold pertumbuhan

top_mean <- function(z, prop) {
  z <- sort(z, decreasing = TRUE)
  if (length(z) == 0) return(NA_real_)
  n_take <- max(1L, ceiling(length(z) * prop))
  mean(z[seq_len(n_take)], na.rm = TRUE)
}

calc_tree_metrics <- function(las_i) {
  if (is.null(las_i) || npoints(las_i) == 0) {
    return(data.frame(
      npts = 0, p95 = NA, p99 = NA,
      top10 = NA, top20 = NA, top30 = NA
    ))
  }

  z <- las_i$Z
  z <- z[is.finite(z) & z >= min_veg_h]

  if (length(z) == 0) {
    return(data.frame(
      npts = 0, p95 = NA, p99 = NA,
      top10 = NA, top20 = NA, top30 = NA
    ))
  }

  data.frame(
    npts  = length(z),
    p95   = as.numeric(quantile(z, 0.95, na.rm = TRUE, names = FALSE)),
    p99   = as.numeric(quantile(z, 0.99, na.rm = TRUE, names = FALSE)),
    top10 = top_mean(z, 0.10),
    top20 = top_mean(z, 0.20),
    top30 = top_mean(z, 0.30)
  )
}

metrics_list <- lapply(las_tree, calc_tree_metrics)
metrics <- bind_rows(metrics_list)

stopifnot(nrow(metrics) == nrow(titik_pokok))

titik_pokok <- bind_cols(titik_pokok, metrics) %>%
  mutate(h_main = p95)

Baseline D1 — Pemetaan Variasi Tinggi Antar-Pokok

Simpan metrik absolut per pokok tanpa memaksakan kelas agronomi yang belum memiliki standar.

Karena belum tersedia standar agronomi minimum pertumbuhan tinggi dan tidak tersedia tinggi lapangan untuk kalibrasi, baseline D1 disimpan sebagai nilai kontinu. Fokusnya adalah pemetaan variasi tinggi antar-pokok, bukan penetapan kelas umur atau diagnosis agronomis.

R CONSOLE
titik_D1 <- titik_pokok %>%
  mutate(
    h_D1     = h_main,
    p99_D1   = p99,
    t10_D1   = top10,
    t20_D1   = top20,
    t30_D1   = top30,
    npts_D1  = npts
  )

7.1 — QC jumlah titik secara data-driven

Tidak digunakan angka minimum titik yang arbitrer. Batas rendah ditentukan dari distribusi jumlah titik pada periode tersebut menggunakan aturan Tukey.

R CONSOLE
q1_n  <- quantile(titik_D1$npts_D1, 0.25, na.rm = TRUE)
q3_n  <- quantile(titik_D1$npts_D1, 0.75, na.rm = TRUE)
iqr_n <- IQR(titik_D1$npts_D1, na.rm = TRUE)
low_n_cut <- max(0, q1_n - 1.5 * iqr_n)

titik_D1 <- titik_D1 %>%
  mutate(
    qc_D1 = case_when(
      is.na(h_D1) ~ "NO_DATA",
      npts_D1 < low_n_cut ~ "LOW_POINTS",
      TRUE ~ "OK"
    )
  )

08

Monitoring Delta Tinggi & Polygon Residual Zone

Delta P95 dipetakan kontinu; residual ditentukan dari quality control dan outlier statistik, bukan threshold agronomi.

Mulai D2, join hasil periode sebelumnya berdasarkan tree_id. Karena belum ada standar agronomi minimum pertumbuhan tinggi, sistem tidak memberi label NORMAL/ANOMALI berdasarkan angka 0.10 m. Nilai pertumbuhan disimpan sebagai delta kontinu, sedangkan residual zone dipakai untuk re-checking kasus yang secara teknis/statistik tidak konsisten.

8.1 — Bawa histori D1 dan tambahkan D2

R CONSOLE
prev_D1 <- st_read(
  "output_D1/shapefile/hasil_tinggi_pokok_D1.shp"
)

hist_D1 <- prev_D1 %>%
  st_drop_geometry() %>%
  select(tree_id, h_D1, p99_D1, t10_D1, t20_D1, t30_D1, npts_D1, qc_D1)

titik_D2 <- titik_pokok %>%
  left_join(hist_D1, by = "tree_id") %>%
  mutate(
    h_D2    = h_main,
    p99_D2  = p99,
    t10_D2  = top10,
    t20_D2  = top20,
    t30_D2  = top30,
    npts_D2 = npts,
    dh_D2   = h_D2 - h_D1
  )

8.2 — Residual detection: teknis + outlier statistik

Residual bukan diagnosis agronomis. Ia adalah flag untuk kasus yang perlu re-checking karena data tidak tersedia, jumlah titik sangat rendah relatif terhadap populasi, atau delta berada jauh di luar distribusi mayoritas pokok pada periode yang sama.

R CONSOLE
# Batas jumlah titik rendah — Tukey lower fence
q1_n2  <- quantile(titik_D2$npts_D2, 0.25, na.rm = TRUE)
q3_n2  <- quantile(titik_D2$npts_D2, 0.75, na.rm = TRUE)
iqr_n2 <- IQR(titik_D2$npts_D2, na.rm = TRUE)
low_n2_cut <- max(0, q1_n2 - 1.5 * iqr_n2)

# Batas delta residual — Tukey fences
q1_d  <- quantile(titik_D2$dh_D2, 0.25, na.rm = TRUE)
q3_d  <- quantile(titik_D2$dh_D2, 0.75, na.rm = TRUE)
iqr_d <- IQR(titik_D2$dh_D2, na.rm = TRUE)
low_d  <- q1_d - 1.5 * iqr_d
high_d <- q3_d + 1.5 * iqr_d

titik_D2 <- titik_D2 %>%
  mutate(
    residual_reason = case_when(
      is.na(h_D1) | is.na(h_D2) ~ "NO_DATA",
      npts_D2 < low_n2_cut ~ "LOW_POINTS_D2",
      dh_D2 < low_d ~ "DELTA_LOW_OUTLIER",
      dh_D2 > high_d ~ "DELTA_HIGH_OUTLIER",
      TRUE ~ "OK"
    ),
    residual_flag = residual_reason != "OK"
  )
▲Interpretasi aman
Delta negatif tidak otomatis berarti pokok bermasalah, dan delta kecil tidak otomatis berarti pertumbuhan terhambat. Tanpa standar agronomi dan data tinggi lapangan, keduanya dipertahankan sebagai nilai terukur. Hanya kasus residual yang diprioritaskan untuk re-checking.

8.3 — Buat polygon residual zone dari buffer 2 m

Setiap pokok residual dikonversi menjadi polygon buffer 2 m. Polygon tidak didissolve secara default agar tree_id, delta, dan alasan residual tetap dapat ditelusuri.

R CONSOLE
# Attribute residual point
residual_attr <- titik_D2 %>%
  filter(residual_flag) %>%
  st_drop_geometry() %>%
  select(tree_id, h_D1, h_D2, dh_D2, npts_D2, residual_reason)

# Polygon buffer 2 m hanya untuk TREE_ID residual
residual_zone_D2 <- buffer_pokok %>%
  select(tree_id) %>%
  inner_join(residual_attr, by = "tree_id")

st_write(
  residual_zone_D2,
  "output_D2/shapefile/residual_zone_D2.shp",
  delete_layer = TRUE
)
