# Scientific Notes — v0.4.1

- P95 adalah estimator tinggi utama sementara, bukan standar biologis final.
- P99 dan Top10/20/30 disimpan untuk evaluasi metode.
- nCHM adalah output visual/QC, bukan sumber utama tinggi per pokok.
- Delta negatif tidak otomatis berarti pokok bermasalah.
- Delta kecil tidak otomatis berarti pertumbuhan terhambat.
- Residual zone adalah prioritas re-check berbasis kualitas data dan outlier statistik.
- Terrain harus konsisten antarperiode. Jika terrain fisik tidak berubah, menggunakan DTM referensi yang sama pada periode lanjutan dapat mengurangi bias antarperiode.
